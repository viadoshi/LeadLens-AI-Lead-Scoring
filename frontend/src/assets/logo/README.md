# LeadLens Logo Directory

Place your official LeadLens logo files here.

### Recommended Files:
- `leadlens-logo.svg` (vector format recommended)
- `leadlens-logo.png` (high-resolution transparent PNG)

The logo component (`src/components/layout/Logo.jsx`) is configured to load from this folder.
When your logo is placed here, update `src/components/layout/Logo.jsx` (or place `leadlens-logo.svg` in this directory) to immediately update across the entire application shell without touching individual pages.
